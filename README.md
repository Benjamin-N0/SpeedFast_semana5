## Descripcion de esta semana
Durante esta quinta semana desarrollarás una actividad formativa individual titulada "Sincronizando procesos en sistemas concurrentes". En esta tarea deberás diseñar y modificar una estructura de clases en Java que utilice Thread, Runnable y mecanismos de sincronización para coordinar la ejecución de múltiples tareas en paralelo.
Diseñarás un sistema orientado a objetos que represente diversos actores accediendo a recursos compartidos, aplicando técnicas de control de concurrencia para evitar condiciones de carrera y garantizar la integridad de los datos.

## Clonar proyecto y ejecutar proyecto

1. Copiar la URL del repositorio de GitHub.
2. Abrir IntelliJ IDEA.
3. Seleccionar File → New → Project from Version Control.
4. Seleccionar Git.
5. Pegar la URL del repositorio.
6. Seleccionar la carpeta donde se guardará el proyecto.
7. Presionar Clone.
8. Abrir Main.java y ejecutar el programa.
